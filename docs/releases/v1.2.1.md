## Summary

Superkeet v1.2.1 is a production-readiness release focused on release safety, permissions reliability, setup recovery, and local privacy controls.

## What's Changed

- hardened the release workflow so production releases require Developer ID signing and notarization
- made release tags fail if they do not match the version in `Info.plist`
- signed the bundled `parakeet` engine with the same microphone entitlement as the app
- added notarization validation with `stapler` and Gatekeeper assessment during packaging
- improved local install signing by supporting `CODESIGN_IDENTITY` in `install.sh`
- flipped the app icon horizontally so the parakeet reads in the intended direction
- fixed microphone setup recovery by triggering the native microphone permission prompt from Settings
- refreshed setup readiness after returning from System Settings
- made recording start wait for daemon confirmation before showing recording UI
- fixed hotkey event-tap retry recovery and auto-paste fallback behavior
- flushed pending history and usage-stat saves during shutdown
- added clearer privacy messaging and reset controls for aggregate usage stats

## Bundled Engine

- bundles `parakeet-cli` v0.1.4

## Install / Upgrade

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

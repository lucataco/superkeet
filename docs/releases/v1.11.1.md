## Summary

Superkeet v1.11.1 closes a way for a dictation to be run as an Actions command,
and stops the menu from saying "Transcribing…" after you cancel. The bundled
speech engine is unchanged.

## What's Changed

### A dictation stays a dictation

- Pressing the Actions shortcut while a dictation was still being transcribed
  could send that dictation's text to Actions instead of typing it. This
  applied to Actions push-to-talk, and to the Actions toggle shortcut when
  listening sessions are off. Whether a recording is a dictation or a command
  is now fixed when it starts, and a new recording cannot begin until the
  current one has finished. The problem was found by reading the code and was
  not reproduced in the running app.

### Cancelling

- After you cancel a recording with Escape, the menu no longer shows
  "Transcribing…" or the orange icon while the engine lets go of the session.
- Starting a new recording in that short window is ignored silently. It used
  to beep and say "Still transcribing".
- If the speech engine stops at the moment a recording is starting, Superkeet
  reports "Transcription failed" rather than the "couldn't start" notice.

## Speech engine

Bundles [parakeet-cli v0.1.13](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.13)
(daemon protocol 2), unchanged from v1.11.0.

## Validation

- A new test runs silent recordings against the real speech engine: one from
  start to finish, a second recording refused while the first is transcribing,
  and cancelling before the engine starts, while recording and while
  transcribing.
- The automated suite passes (1096 tests, 17 opt-in tests skipped).
- Recordings with real speech were not run for this release by the automated
  rig.

## Install / Upgrade

Download `Superkeet-1.11.1.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

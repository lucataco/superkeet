## Summary

Superkeet v1.9.3 bundles a faster speech engine and fixes a setup problem. The
engine is ready sooner after launch, uses less memory while it waits, and
transcribes faster, with the same transcripts on our test recordings. On some Macs, setup no
longer refuses to download the speech model with "Not enough free disk space"
when plenty of space is free.

## What's Changed

### Speech engine

- The bundled speech engine is now parakeet-cli v0.1.11. On an M2 Pro it was
  ready 0.19 s sooner after launch, held about 196 MiB less memory while idle,
  and transcribed a 48 s recording in 1.19 s instead of 1.43 s. Transcripts of
  that recording and of the synthetic regression set match v1.9.2.
- On Apple silicon, the engine now uses one thread per performance core. This
  was measured only on an M2 Pro. Chips with four performance cores, such as the
  base M1, M2 and M3, use four threads and have not been measured.

### Setup

- The speech model download no longer reports a full disk when macOS returns 0
  for the space available for important downloads. Superkeet now also checks the
  volume's plain free space, and still requires about 1.5 GB.

### Release process

- The release job pins the Rust toolchain action to a commit on its `master`
  branch. The previous pin was a commit that no branch referenced anymore.

## Speech engine

Bundles [parakeet-cli v0.1.11](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.11)
(daemon protocol 2), updated from v0.1.10.

## Install / Upgrade

Download `Superkeet-1.9.3.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

## Summary

Superkeet v1.6.0 adds transcript recovery, explicit phrase replacements, and optional spoken correction commands, with a session-aware speech engine and reliability fixes throughout recording and delivery.

## What's Changed

- complete long and multiline transcript messages are preserved, including Unicode characters split across subprocess reads; oversized or incomplete messages fail explicitly
- the menu bar now shows Transcribing until a definite complete, partial, empty, or failed result arrives, with accessible status announcements
- recording sessions retain their original destination and metadata through completion, and a new recording waits for the pending result
- Copy Last Transcript, Copy Original Transcript, and Undo Text Changes and Copy are available without enabling saved history
- saved history includes original text and partial-result status, while older history remains readable
- personal whole-phrase replacements can be scoped to an application; replacements do not cascade
- optional standalone spoken commands support scratch that, replace X with Y, and undo last correction within a recording
- filler removal preserves er, err, ER, hmm, ah, like, and deliberate repetitions
- automatic paste rechecks the target application, Accessibility permission, and clipboard generation before sending Cmd+V
- toggle-key autorepeat is consumed, and a second press cancels pending startup
- malformed replacement commands no longer crash the app
- history and usage statistics preserve unreadable originals before saving new data, with visible persistence errors
- model-preparation errors produce a retryable failure state, and repeated short-lived engine crashes respect restart limits
- microphone selection and readiness use shared native CoreAudio enumeration
- version lookup, engine selection, persistence scheduling, and daemon internals were simplified; obsolete code and explanatory source comments were removed
- optional Homebrew synchronization detects unavailable credentials and reports the issue separately from app publication

## Bundled Engine

Bundles [parakeet-cli v0.1.6](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.6), which introduces protocol-1 session completion, bounded audio segments, independent collection, overflow reporting, and stop-time draining.

## Validation and Known Limitations

- 195 Swift tests, 47 engine tests, and four regression-scoring tests pass locally
- debug/release builds, strict lint, engine formatting/Clippy, benchmark compilation, and the real-daemon protocol smoke test pass
- native device names matched all four available engine inputs on the test Mac
- four of eight strict synthetic-audio scenarios pass; auth/off substitutions, correction-marker recognition, repeated answers, and long-session word/count errors remain documented failures
- phrase replacements operate after recognition and do not bias the speech model
- spoken correction commands are opt-in and require punctuation or line boundaries; Copy Original remains available for recovery
- restoring text copies it to the clipboard; paste it manually to replace text already inserted into another application
- persistent transcript history remains opt-in; the app does not retain an audio archive

## Install / Upgrade

Download `Superkeet-1.6.0.zip` from this release and move Superkeet to Applications. Release packaging signs and notarizes the app and includes a SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

## Summary

Superkeet v1.9.0 lets Actions Mode finish commands before you finish saying
them. Say "open the Notes app and create a new note" and Notes opens while you
name it, then ⌘N is pressed as the sentence settles — no pause, no waiting for
the final transcript. Commands phrased conversationally ("once you're there,
can you create a new note") or slightly garbled by the recogniser now run as
built-in steps instead of falling back to the planner. The bundled speech
engine (parakeet-cli v0.1.9) streams interim text every 0.5 s. This release
also hardens quitting, permissions and settings persistence.

## What's Changed

### Actions while you speak

- The last clause of a command now runs early when it is safe and has settled:
  an app open, a URL, a shortcut recipe (⌘N, ⌘T, Photo Booth's shutter), or a
  web search once the recogniser ends the sentence. It must read the same on
  two interim updates in a row, or hold still for 0.7 s. Typing never runs
  early, so half-heard words are never typed.
- An open waits while a longer installed app name could still be coming
  ("Safari" vs "Safari Technology Preview").
- Steps that already ran are re-checked against every interim update; if a
  finished clause changes meaning, early execution stops for that utterance.
  A planner-only clause stops early execution until the recogniser corrects it.
- Routing reads through lead-ins ("can you …"), garbled words before a request
  ("umce right there can you create a new note"), and reactions glued onto an
  open ("open up x.com Nice"). "go search …" counts as a web search, and
  "… the notes app for me" ends the app name at "for".
- Listening sessions detect a pause after 1 s (was 1.25 s) and only count new
  words as speech, so the engine re-reading words it already heard no longer
  keeps a take open.
- On the demo recording, all eight clauses now route to built-in actions (was
  four of seven), and every action is dispatched no later than the demo video
  shows it. An offline replay test checks this timeline in CI.

### Quitting and lifecycle

- Quit can no longer hang: cleanup has a 6 s limit, after which the speech
  engine is force-killed. Hotkeys stop first, the engine can't be relaunched
  mid-quit, and MCP servers are disconnected (and force-killed if they ignore
  the stop signal). Cancelled model downloads are force-killed after 2 s.
- Closing the Setup window now counts as skipping setup, so shortcuts and the
  engine still start.
- The "Failed to start Parakeet" alert no longer appears when quitting and now
  opens in front of other windows.
- ⌘C / ⌘V / ⌘A / ⌘Z / ⌘W work in Settings, History and Setup text fields.

### Permissions and recording

- Recording checks microphone permission first. If it's denied, Superkeet says
  so and offers to open System Settings, instead of reporting "No speech
  detected".
- Turning off Accessibility is detected within 30 s; shortcuts resume on their
  own once access is granted again.
- New shortcuts must include ⌘, ⌥ or ⌃ (except fn and F1–F20), so a plain key
  can't stop working for typing in every app.
- Changing the microphone during a recording now takes effect as soon as the
  take finishes.
- Recordings stop automatically after 15 minutes and the audio so far is
  transcribed.
- A model download that makes no progress for 90 s fails with a clear message
  instead of waiting forever.

### Clipboard and data safety

- When the original clipboard is restored after pasting, the transcript is
  marked transient so clipboard managers don't record it, and the restore waits
  0.75 s (was 0.3 s) for apps that read the clipboard late.
- Unreadable phrase-replacement and MCP server files are backed up before the
  next save instead of being overwritten. Phrase replacements load even with
  missing or extra fields.
- The action log trims to 75% of its limit, so it's no longer rewritten on
  every entry once full.

## Speech engine

Bundles [parakeet-cli v0.1.9](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.9)
(daemon protocol 2). Interim `partial` events arrive every 0.5 s of captured
audio (0.75 s in v0.1.8) and carry `audio_ms`, how much of the recording each
one covers. Sessions without partials, including every dictation recording, are
unchanged. Superkeet still accepts protocol 1 or 2 engines.

## Install / Upgrade

Download `Superkeet-1.9.0.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

## Summary

- initial release of Superkeet, a macOS menu bar app for local voice-to-text
- powered by an embedded Parakeet TDT 0.6B engine via ONNX Runtime
- menu bar app with no Dock icon, global shortcuts for toggle recording and push-to-talk
- floating recording overlay with mini and classic modes
- searchable local history and aggregate usage stats
- setup diagnostics for microphone access, engine presence, runtime directory, and daemon state
- 100% local transcription via bundled `parakeet` engine

## Summary

Superkeet v1.5.6 is a reliability pass for recording sessions, the overlay clock, and global hotkeys. No new features — the focus is fixing bugs that showed up after a few takes.

## What's Changed

- overlay timer now starts at `0:00` on every new recording (it previously kept counting in the background)
- cancelled takes (Escape) no longer paste, copy, or save leftover transcript
- failed starts surface an error instead of a dead hotkey
- a crashed speech engine no longer leaves recording stuck until quit
- Push to Talk no longer stops a toggle-started recording
- rebinding a shortcut no longer fires the old combo
- hold-PTT no longer types repeated characters into the focused app
- overlay meter start/stop no longer races, and the meter uses the selected mic
- notch and island overlays no longer steal menu-bar clicks (stop with the hotkey or Escape)
- global hotkeys stay disarmed until onboarding completes

## Bundled Engine

- bundles `parakeet-cli` v0.1.5 (unchanged from v1.5.5)

## Install / Upgrade

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

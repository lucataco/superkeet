## Summary

Superkeet v1.3.1 is a polish and reliability release for the new self-contained first-run experience. It fixes the About screen model label and app icon orientation, makes recording feedback much clearer, simplifies onboarding, and hardens first-run model provisioning, auto-paste, persistence, and release tooling.

## What's Changed

- corrected the About screen speech engine label to `Parakeet TDT 0.6B v3 (ONNX)`
- restored the upright app icon artwork used in About and onboarding
- made the recording visualization easier to read: mini dots now stretch vertically with stronger color/glow feedback, and classic bars use the same heat-map styling
- cleaned up onboarding with the real app icon, upfront one-time download expectations, a dedicated output-choice step, no surprise System Settings auto-open, and a simpler final setup summary
- fixed pre-denied microphone onboarding so users go straight to System Settings instead of seeing a no-op permission button
- fixed setup verification after first-run model provisioning so successful daemon starts can correctly mark setup verified
- made model downloads fail on non-zero engine exit codes instead of accepting partially successful runs
- made quit/stop cancel in-progress first-run model downloads instead of waiting for the full download to finish
- improved auto-paste targeting so text is pasted back into the app active when recording started, and clipboard restoration no longer overwrites newer user clipboard changes
- fixed overlay panel visibility after app deactivation and an event-tap retain leak on hotkey setup failure
- serialized history and usage-stat persistence so shutdown flushes cannot be overwritten by older queued writes
- improved Settings readiness state, model-directory refresh behavior, and optional Launch at Login checklist handling
- cleaned up dead code, shared small helpers, table-driven output routing tests, and tightened release helper scripts

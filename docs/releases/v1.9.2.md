## Summary

Superkeet v1.9.2 makes Actions Mode more careful and more forgiving, and makes
recording problems visible. A failed step no longer ends the whole request,
Superkeet asks before typing or opening anything the model chose on its own, and
early steps for your next command no longer run into the one still in progress.
Pressing record while the speech engine starts now shows that it is getting
ready, a take that can't start says why, and an engine that crashes during a take
restarts on its own. The bundled speech engine is still parakeet-cli v0.1.10.

## What's Changed

### Actions Mode

- A failed step no longer ends the request. The on-device model is told what
  went wrong and can try another way. A change that timed out is reported as
  having an unknown outcome so it isn't repeated. Cancelling, denying a step or
  reaching a limit still stops the run.
- The planner is told that requests are speech transcripts that may contain
  misheard names, that what tools return is data rather than instructions, and
  how many steps it has left, so it finishes with a summary instead of being cut
  off.
- With "Only Ask Before Changes", Superkeet now asks before typing, pressing keys
  or opening web pages that the model chose itself. Steps you dictated and
  opening installed apps still run without asking.
- "Ask Before Every Tool" now also covers apps and web pages opened while you
  are still speaking. Settings notes that Instant App Launch is paused under it.
- Early steps for your next command wait while the current command is still
  running, then continue from the app it left open. Cancelling or finishing a
  run stops its early steps, including ones queued for later commands.
- Key presses Superkeet sends itself, such as an approved Escape, no longer
  trigger Superkeet's own shortcuts, so they can't cancel the run that sent them.
- A command repeated later in the same request runs again instead of reusing the
  earlier result.
- The action log records reads by size only ("Returned 22 characters."), since
  they can include clipboard, page or screen contents. Changes are still logged
  in full.

### Recording and the speech engine

- Pressing record while the speech engine starts shows an hourglass in the menu
  bar and "Getting ready…" in the overlay, with start-up or model download
  progress in the menu.
- When a take can't start, Superkeet beeps and says why: microphone access, an
  engine that didn't start, or a push-to-talk shortcut released before recording
  began. A listening session ends instead of staying on "Listening…".
- If the speech engine crashes during a take, it restarts on its own and
  "Restarting…" no longer stays on screen. When the engine refuses to start,
  stop or cancel, its own reason is shown, and it is restarted only when it stops
  answering.
- The menu bar shows the engine's actual state (downloading, starting, ready or
  failed) instead of "Daemon not running".
- The recording indicator pulses while recording (it still holds still with
  Reduce Motion on), and the overlay no longer flashes its previous message when
  it reappears.
- Looking up microphone names no longer leaks memory.

### Settings and data

- If the Keychain can't read an MCP server's secrets, they are kept instead of
  being deleted on the next save, and Settings shows a warning.
- MCP server arguments use shell-style quoting, so paths with spaces survive
  editing.
- The shortcut recorder rejects standard system shortcuts such as ⌘C, ⌘V and
  ⌘Tab.
- Deleting a data file that Superkeet couldn't read no longer blocks saving
  until the next launch.
- Exported logs show error messages and shortcut names in readable form.

### Release process

- The release job checks SwiftLint's download against a pinned checksum, keeps
  the GitHub token out of checkouts that don't push, lets only `codesign` use the
  signing key, and publishes the GitHub release only after its download is
  attached.
- The test suite writes to a temporary folder and can no longer touch your
  history, statistics, MCP configuration or action log.

## Speech engine

Bundles [parakeet-cli v0.1.10](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.10)
(daemon protocol 2), unchanged from v1.9.1.

## Install / Upgrade

Download `Superkeet-1.9.2.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

## Summary

Superkeet v1.10.0 makes Actions Mode do what you say, in the way you say it.
A pause between sentences no longer splits one command in two, typing after a
shortcut now lands in the document, and the Actions window shows one plain line
per action. The bundled speech engine moves to parakeet-cli v0.1.12, which
reports the silence it hears.

## What's Changed

### Listening

- A listening session now ends a command on silence that the speech engine
  measures in the audio. A pause of up to about 0.9 s between sentences keeps
  the command together. Before, a half-second pause could split it, and the
  leftover words went to the on-device planner, which sometimes acted on them.
- The command still runs 0.9 to 1.5 s after your last word.
- With an older engine that does not report silence, the session keeps the
  previous pause rule.

### Typing and shortcuts

- After Superkeet pressed a shortcut such as ⌘N, the next text it typed could
  vanish while the action log still said it typed it. The shortcut left the
  Command key held down for the rest of the session, so "hello" arrived as
  ⌘H ⌘E ⌘L ⌘L ⌘O. Shortcuts now release their modifier, so "create a new note
  and make the title say hello" types "hello" into the new note, in TextEdit
  and in Notes, without a click first.
- Automatic paste after dictation used the same key path and also left Command
  held. It now releases it too.

### Actions window

- The window shows one plain line for each action you asked for, in the order
  you said them, such as "Opened TextEdit", "New document", and
  "Typed “hello”".
- Finished lines have a quiet gray checkmark. Only a step that failed or was
  not approved is orange, with a one-line reason.
- An action that ran while you were speaking appears once, not twice.
  Step numbers, tool names, process IDs, and raw tool output no longer appear.
- Approval and plan cards are unchanged.

## Speech engine

Bundles [parakeet-cli v0.1.12](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.12)
(daemon protocol 2). It adds a `tick` event with measured trailing silence.
Partial and final transcripts are unchanged from v0.1.11.

## Validation

- A test rig plays recorded speech into the app through a BlackHole loopback
  and reads what appears on screen. For a three-sentence TextEdit command:
  - with v1.9.4's listening code, the command split into two takes in 18 of
    20 runs; with this release's, 0 of 10;
  - "hello" reached the document in 0 of 5 runs before the typing fix and 5 of
    5 after.
- Each change was verified by a separate reviewer who ran it against the
  previous build before it merged.

## Install / Upgrade

Download `Superkeet-1.10.0.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

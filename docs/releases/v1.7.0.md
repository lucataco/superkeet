## Summary

Superkeet v1.7.0 introduces **Actions Mode**: an opt-in, on-device agent that
turns a spoken command into tool calls on local MCP servers. It is planned with
Apple Intelligence, requires your approval before each call, and keeps the
existing local dictation flow unchanged.

## What's Changed

- Actions Mode: a Command Mode shortcut records a task, plans it on-device with
  the Foundation Models framework, and runs MCP tool calls
- MCP server management in a new **Actions** settings tab: add, edit, test,
  enable, and reconnect servers using a Claude/Cursor-compatible
  `mcpServers.json`
- Approval HUD showing the tool, its risk, its arguments, and a live step
  counter, with Approve/Deny; Escape stops an action
- Risk-aware approval policy (ask for everything by default; optionally auto-run
  read-only tools), step budget, per-tool timeout, argument-size cap, and tool
  count cap
- Local, redacted action audit log (`action-audit.log`) with sensitive-looking
  argument keys and bearer/key-value secrets masked
- Optional Actions onboarding step and a dedicated menu bar status/Stop Action
- Login-shell `PATH` resolution so `npx`/`uvx` MCP servers launch from the GUI app
- Bundles the official MCP Swift SDK; the app targets macOS 26 for Actions and
  macOS 14 for dictation

## Bundled Engine

Still bundles [parakeet-cli v0.1.6](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.6);
the transcription path is unchanged.

## Validation and Known Limitations

- debug/release builds, strict lint, and the Swift test suite pass
- MCP connect, tool listing, and tool calling were verified end-to-end against a
  local reference MCP server
- Actions Mode requires macOS 26 with Apple Intelligence; it is unavailable on
  earlier systems
- The on-device model has no image input, so computer-use servers work through
  accessibility/element tools rather than screenshots
- The model has a small context window; tool results are truncated and the number
  of tools per plan is capped
- MCP servers are user-installed; Superkeet does not bundle Node, Python, or MCP
  servers, and Actions Mode is not compatible with a Mac App Store sandbox
- The live model call could not be exercised in CI because Apple Intelligence is
  not enabled on the build host

## Install / Upgrade

Download `Superkeet-1.7.0.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

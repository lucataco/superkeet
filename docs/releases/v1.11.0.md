## Summary

Superkeet v1.11.0 makes Actions Mode understand commands said in your own
words, act on the last step of a command sooner, and stay out of the way while
you speak. Commands such as "I need the calculator" or "start a fresh document"
used to fail, most of them at "No MCP servers are enabled". They now run as
built-in actions. The bundled speech engine moves to parakeet-cli v0.1.13.

## What's Changed

### Commands in your own words

- **Settings ▸ Actions ▸ Understand loosely worded commands** reads a command
  that no built-in phrasing matches and turns it into a built-in action: open
  an app or a website, search the web, make a new item or tab, type, save,
  close, undo, redo, select all or quit.
- It uses the on-device model by default (about 0.9 s a command). You can
  instead choose a local decision model such as `clef-flash` served by Ollama
  on your Mac, which needs 12 GB or more of memory, or turn it off.
- Text to type, a search and a website are always taken from your own words.
  If the model offers words you did not say, Superkeet does not act on them.
  An app does not have to be named ("check my email" opens Mail), but it must
  be installed.
- Shortcuts it picks keep their usual approval: ⌘S, ⌘W, ⌘Z, ⌘A and ⌘Q still ask
  first under the default policy.
- Anything it cannot place goes to the planner as before.

### Planning without servers

- The planner always has the built-in actions, so a command no longer stops at
  "No MCP servers are enabled". Only a request about the active browser tab
  still needs its server.
- When the planner answers in words instead of acting, you see its answer and a
  hint, and nothing is ticked off as done.
- The planner is loaded as soon as you start speaking a command, and it gives
  the same plan for the same command every time.

### The last step runs sooner

- The speech engine now reports a pause the moment it starts, along with how
  much of your speech the latest text covers. The last step of a command (a
  shortcut, a search, or typing) runs once the text has heard your last words.
- On a replayed three-sentence command, the last step ran 306 to 336 ms after
  the last word, against 294 to 708 ms (median 469) with the previous engine.
  A listening take ended 936 to 966 ms after the last word, against 900 to
  1378 ms.

### A compact pill under the notch

- While you speak, the Actions window is a single line under the camera notch
  (under the menu bar on displays without one). It shows your latest words,
  then a check and the action's name when a step completes.
- An answer in words stays for about 5 seconds. Approvals and plans still open
  the full card. Click the pill to see the transcript and checklist.
- Turn off **Settings ▸ Actions ▸ Compact pill under the notch** to always use
  the card.

### Fixes

- "Pull up github dot com" opens the site instead of searching for it.
- The menu shows the shortcuts for recording and listening for actions.

## Known issues

- "Put hello world in there" types "hello world in there", and "Title this one
  grocery list" types "one grocery list".

## Speech engine

Bundles [parakeet-cli v0.1.13](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.13)
(daemon protocol 2). It adds pause ticks and `decoded_ms`; older engines keep
working with the previous timing.

## Validation

- 71 commands written the way people say them, held out from development:
  51 run with the built-in phrasings alone, 66 with the on-device model or
  `clef-flash` behind them. Each model made two wrong actions on that set; one
  of the on-device model's was ⌘W for "get out of Spotify", which asks first.
- `swift test`: 1093 tests pass. The engine's 78 tests pass.
- The release was not run through a microphone before tagging. A locally built
  app does not have the installed app's Microphone and Accessibility
  permissions, so the live check runs on this signed build.

## Install / Upgrade

Download `Superkeet-1.11.0.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

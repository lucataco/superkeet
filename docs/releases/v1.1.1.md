## Summary

Superkeet v1.1.1 is a patch release focused on daemon lifecycle reliability, hotkey behavior, and output privacy.

## What's Changed

- fixed daemon startup cleanup so failed launches do not leave unreachable background processes
- fixed shutdown timeout handling so stubborn daemon processes can be killed reliably
- prevented duplicate daemon starts during concurrent startup requests
- made recording state updates depend on parsed daemon JSON responses instead of substring checks
- changed Escape to send a true daemon `cancel` command rather than stop-and-transcribe
- fixed quick push-to-talk taps so key release can stop a pending start request
- consumed handled global hotkey events so shortcuts do not leak into the active app
- rejected duplicate Toggle Recording and Push to Talk shortcuts in setup
- restored the previous clipboard after auto-paste when "Copy to Clipboard" is disabled
- kept app-side output routing as the single clipboard owner
- improved socket path validation and readiness probing

## Bundled Engine

- bundles `parakeet-cli` v0.1.4

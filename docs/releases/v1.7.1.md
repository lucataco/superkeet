## Summary

Superkeet v1.7.1 makes Actions Mode more reliable and quieter. It fixes a crash
where a spoken command could fail with "That request needed more context than the
on-device model allows", handles URLs and named browsers correctly, and shows the
floating HUD only when you need to approve something or a session finishes.

## What's Changed

- Actions Mode now measures the real cost of every tool definition against the
  on-device model's 4,096-token context and only sends the task-relevant subset
  that fits on macOS 26.4+ (with a conservative schema-pruned estimate on
  macOS 26.0–26.3)
- Tool selection ranks by relevance to the spoken request and round-robins across
  enabled servers, so each server stays represented even when the window can only
  hold a subset
- If a plan still overflows before any tool runs, Superkeet automatically retries
  with a smaller tool budget instead of failing immediately
- Tool results fed back to the model are trimmed to 800 characters (from 1,200)
  to leave headroom in the transcript for multi-step tasks
- URL arguments are now normalized before a tool runs: a bare domain such as
  `youtube.com` becomes `https://youtube.com`, so URL-validating tools (for
  example Chrome DevTools) no longer reject the call
- Planning instructions now tell the model to include a scheme in URLs and to use
  the browser the user names rather than another browser's automation tools
- Naming a browser other than Chrome now withholds the Chrome DevTools tools for
  that request, so "open Helium and go to youtube.com" opens Helium instead of
  silently driving Chrome
- The floating HUD is now quieter: a compact pill stays in the top-center while
  an action runs, then shows a concise result when it finishes instead of live
  progress and a per-tool activity log (successful results auto-dismiss; failures
  stay until dismissed). Approvals replace the pill with an Approve/Deny prompt
- The menu bar is icon-only: no status text, with the icon switching between idle,
  recording (red mic), and working on an action (purple wand)

## Install / Upgrade

Download `Superkeet-1.7.1.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

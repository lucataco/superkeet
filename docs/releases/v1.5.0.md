## Summary

Superkeet v1.5.0 improves the local development and source-install experience, refreshes Settings with a more native macOS layout, and adds an appearance preference for System, Light, or Dark mode.

## What's Changed

- `swift run` can now bootstrap the local speech engine automatically: if no `parakeet` binary is found, Superkeet clones `lucataco/parakeet-cli` into `.build/parakeet-cli`, checks out the pinned engine ref, and builds `parakeet` with Cargo.
- `install.sh` now has the same source-install behavior, so the README-recommended install flow no longer requires users to prebuild `parakeet-cli` manually.
- added explicit development engine discovery for `PARAKEET_BINARY_PATH`, `PARAKEET_CLI_PATH`, `PARAKEET_SOURCE_DIR`, `.build/parakeet-cli`, sibling checkouts, Cargo/Homebrew paths, and `PATH`.
- improved missing-engine errors so `swift run` users get actionable setup guidance instead of a misleading app-reinstall message.
- redesigned Settings around a native `NavigationSplitView` with larger panes, grouped forms, clearer section headers, and a polished sidebar.
- added an Appearance setting to follow the system, force Light, or force Dark mode.
- reorganized General, Output & Privacy, and Advanced settings into clearer grouped controls while preserving the privacy-safe defaults.
- added tests for appearance preferences and development `parakeet` binary discovery.

## Bundled Engine

- bundles `parakeet-cli` v0.1.5 (unchanged from v1.4.0)

## Install / Upgrade

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

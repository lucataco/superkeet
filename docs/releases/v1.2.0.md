## Summary

Superkeet v1.2.0 is a UI-focused release that adds an at-a-glance usage summary and simplifies the Settings experience.

## What's Changed

- added a usage stats header at the top of Settings showing words dictated, average speaking rate (WPM), and estimated time saved
- tracked these metrics in a privacy-safe aggregate store that records numbers only, never transcribed text, and works whether or not Save History is enabled
- introduced a shared theme for consistent card surfaces, spacing, and corner radii across the app
- simplified the Setup tab: the readiness checklist now collapses to a single "ready" summary when every check passes, and surfaces only failing checks otherwise
- shortened and softened setup and status messaging for a calmer, less cluttered first run
- fixed the Advanced tab header, which previously read "Recording"
- updated the README to match the current Advanced tab options

## Bundled Engine

- bundles `parakeet-cli` v0.1.4

## Install / Upgrade

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

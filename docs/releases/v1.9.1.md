## Summary

Superkeet v1.9.1 makes listening sessions and the speech engine more reliable.
Words spoken while one command finishes are no longer lost, and the speech engine
can no longer keep running after Superkeet crashes. The action bar lists every
step done while you speak, a slightly misheard long app name ("the phone booth")
still opens the right app, and About can check for updates. The bundled speech
engine is parakeet-cli v0.1.10.

## What's Changed

### Listening sessions and Actions Mode

- No more lost words between commands: when a pause ends one command, the engine
  keeps the microphone open and the words spoken while that command finishes
  start the next one. Closing the session releases the microphone.
- The action bar lists every step done while you speak (the newest four), not
  just the latest.
- While you speak, a long app name one or two letters off opens the one
  installed app spelled that way ("the phone booth" → Photo Booth). Short
  misheard names such as "nodes" still wait for the final transcript.
- Macs set up before Actions Mode existed now see "Try Actions Mode…" in the
  menu bar on macOS 26.

### Reliability

- The speech engine shuts down within about a second if Superkeet crashes or is
  force-quit, releasing the model and the microphone. A leftover engine from a
  moved copy of the app is also cleaned up at launch.
- Push-to-talk can no longer get stuck when Secure Input (password fields,
  1Password, Terminal's Secure Keyboard Entry) hides the key release.
- One unreadable history record or day of usage statistics no longer hides the
  rest; the original file is kept.
- If the Keychain refuses an MCP server's secrets, the error is shown and the
  server is not saved without them. A failed engine restart is reported.
- The model folder field applies on Return, focus loss or Browse (and restarts
  the engine) instead of on every keystroke.
- Action-log writes no longer run on the main thread.

### Settings, About and accessibility

- About can check GitHub for a newer release.
- Settings ▸ General can export diagnostics and Superkeet's log since launch to a
  text file for bug reports.
- About and the README credit the Parakeet model (NVIDIA, CC BY 4.0) and its
  ONNX conversion, and describe exactly when Superkeet goes online.
- VoiceOver labels for the overlay's stop and collapse buttons and the history
  search clear button; the recording pulse holds still with Reduce Motion on.
- Pressing record while the last take is still transcribing now beeps and says
  so.

### Release process

- Releases run lint and the full test suite before signing, refuse to overwrite
  an already-published download, and fail if the Homebrew update can't be opened.

## Speech engine

Bundles [parakeet-cli v0.1.10](https://github.com/lucataco/parakeet-cli/releases/tag/v0.1.10)
(daemon protocol 2). `stop` accepts `"keep_warm": true` to keep the microphone
open for the next session, and `serve` exits when the process named by
`PARAKEET_PARENT_PID` is gone. Both are opt-in; Superkeet still accepts
protocol 1 or 2 engines.

## Install / Upgrade

Download `Superkeet-1.9.1.zip` from this release and move Superkeet to
Applications. Release packaging signs and notarizes the app and includes a
SHA-256 checksum file.

Homebrew updates become available after the tap has been synchronized:

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

Uninstalling with `brew uninstall --zap --cask superkeet` now also removes the
downloaded speech model.

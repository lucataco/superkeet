## Summary

Superkeet v1.3.0 makes first run effortless: the app now provisions the on-device speech model itself, so installing Superkeet is all you need — no separate Parakeet setup or manual model download.

## What's Changed

- added a guided first-run onboarding step that downloads the ~670 MB on-device speech model with a live progress bar, per-file detail, and retry on failure
- added a `ModelProvisioning` service that runs the bundled engine's `parakeet download --progress json` and renders its progress natively
- the daemon now provisions the model automatically before starting, even if onboarding was skipped
- added a Speech Model readiness check (with download / re-download) to the Setup tab and a model-status line to diagnostics
- a missing model is now treated as a recoverable first-run download instead of a "reinstall the app" error
- always pass an explicit `--model-dir` so the engine's `download` and `serve` resolve to the same location
- precheck free disk space and verify the download by SHA-256 before starting the daemon
- corrected the model path references to `parakeet-tdt-0.6b-v3` and documented the first-run download

## Bundled Engine

- bundles `parakeet-cli` v0.1.5 (adds machine-readable `download --progress json`)

## Install / Upgrade

```bash
brew update
brew upgrade --cask lucataco/tap/superkeet
```

## Summary

Superkeet v1.4.0 is a production-readiness pass: 22 fixes spanning logging, crash safety, correctness, CI, release tooling, and community files. No new user-facing features beyond a clearer "Apple Silicon required" message on Intel Macs; the focus is reliability and maintainability.

## What's Changed

### Reliability & Crash Safety
- replaced 27 `print()` calls with structured `os.log` logging across all services and views
- fixed force-unwraps in `AppPaths` and `AppReadiness` that could crash on unusual system configurations
- fixed `AudioLevelMonitor` tap leak when `AVAudioEngine.start()` failed (orphaned tap could never be removed)
- fixed `TranscriptionRecord.wordCount` to split on any whitespace (tabs, newlines, NBSP) instead of only single spaces — usage stats are now accurate for multi-line transcriptions
- added `dispatchPrecondition(.onQueue(.main))` to `HotkeyManager` start/stop so future off-main callers fail loudly in debug instead of silently breaking hotkeys
- memoized `runtimeFilesDirectory()` (was calling `FileManager.createDirectory` on every `settings.socketPath` read, 15+ times per daemon lifecycle)

### Apple Silicon Check
- added an architecture readiness check that detects Intel Macs and surfaces a clear "Apple Silicon required" message instead of a confusing engine launch failure
- added `verify_parakeet_architecture` to `install.sh` and `package_release.sh` — refuses to bundle a `parakeet` binary whose architecture doesn't match the host

### Testing
- test count grew from 48 to 87 with new suites for `NDJSONLineBuffer`, `DownloadCollector`, `HistoryStore`, `UsageStatsStore`
- made `NDJSONLineBuffer` and `DownloadCollector` `internal` for direct testing
- `HistoryStore` and `UsageStatsStore` now accept an injectable `fileURL` for test isolation
- added `testUghIsPreserved` covering the filler-word change below

### Lint & CI
- added `.swiftlint.yml` with conservative config (disables noisy length/complexity rules, opts into `force_unwrapping`, `implicitly_unwrapped_optional`, `is_disjoint`, etc.)
- CI now installs SwiftLint and runs `swiftlint lint --strict` — zero violations
- CI now builds the release configuration (`swift build -c release`) in addition to debug
- added `actions/cache@v4` for the SPM `.build` directory
- fixed 5 existing SwiftLint violations the initial lint caught (`isDisjoint`, trailing closure, implicit nil init, `Data()` conversion)

### Release Pipeline
- added `if: always()` keychain cleanup step so the signing keychain is deleted even when the build fails
- replaced the direct push to the Homebrew tap `main` with a branch + `gh pr create` flow for reviewable, rollback-able cask updates
- added `Swatinem/rust-cache@v2` to cache the `parakeet-cli` Cargo build across releases
- made `update_homebrew_cask.py` write atomically via a temp file + `os.replace` (an interrupted write no longer leaves a corrupt cask file that breaks `brew install` for everyone)

### Community & Docs
- added `SECURITY.md` with a private vulnerability disclosure policy
- added `CONTRIBUTING.md` with dev setup, PR checklist, and code style
- added `.github/ISSUE_TEMPLATE/bug_report.md` and `feature_request.md`
- added `AGENTS.md` for AI coding agents working on the repo
- filled in 8 missing release notes (v1.0.0–v1.0.6, v1.1.0) — all 16 tags now have notes

### Polish
- dropped "ugh" from the filler-word list (it is a legitimate interjection users may want preserved)
- added a load-bearing comment to `PasteService` explaining the 150ms/300ms timing constants
- added a comment to `Superkeet.entitlements` explaining why the app is not sandboxed
- added a comment to `Package.swift` clarifying the `Info.plist` `.copy` is for `swift run` only

## Bundled Engine
